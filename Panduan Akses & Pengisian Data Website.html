3. Langkah-Langkah Pengisian

✅ Langkah 1: Admin — Atur Campaign

  1. Login ke /login
  2. Klik menu Campaign di sidebar kiri
  3. Isi:
    • Nama Program — "Program Apresiasi Penulis"
    • Tanggal Mulai — 26 Juli 2026 00:00 WIB
    • Tanggal Selesai — 4 Agustus 2026 23:59 WIB
    • Kuota Total — 50 peserta
    • Status Aktif — Aktif (atau Nonaktif jika ingin tutup manual)
  4. Klik Simpan

✅ Langkah 2: Semua Anggota Tim — Isi Profil

  1. Buka /team/login di browser
  2. Masukkan email dan password password123
  3. Setelah login, klik Edit Profil
  4. Lengkapi:
    • Foto — pilih file, crop lingkaran, zoom jika perlu
    • Bio — cerita singkat tentang diri Anda (max 3 paragraf)
    • Skills — pisahkan dengan koma (contoh: Desain Grafis, Copywriting, Manajemen)
    • Kontak — nomor WhatsApp aktif, email, LinkedIn (opsional)
    • Quote — satu kalimat motivasi
  5. Klik Simpan
  6. Jangan lupa Ganti Password di halaman yang sama

✅ Langkah 3: Admin — Cek Hasil

  1. Buka https://mughisciptamedia.com/tim
  2. Pastikan foto dan data semua anggota tampil benar
  3. Buka https://mughisciptamedia.com/transformasi
  4. Pastikan badge status campaign sesuai (Sedang Berlangsung)
  5. Pastikan tombol "Daftar Sekarang" aktif dan bisa diklik
